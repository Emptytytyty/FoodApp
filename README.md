# FoodApp - Трекер калорий

**FoodApp** — это веб-приложение для ежедневного подсчёта калорий, которое помогает отслеживать свой рацион и достигать целей в питании. Проект создан с использованием современных инструментов для быстрой и удобной работы.

## 🚀 Суть проекта

Приложение создано, чтобы помочь вам контролировать потребление калорий. Основные возможности включают:

*   **Ведение дневника питания**: Добавляйте съеденные продукты и их количество за каждый день.
*   **Подсчёт калорий**: Автоматический расчёт общей калорийности и питательной ценности (БЖУ) за день.
*   **Визуализация данных**: Отслеживайте прогресс через интуитивно понятный интерфейс.
*   **Календарь**: Просматривайте историю питания, легко переключаясь между месяцами и днями.

## 🛠️ Технологический стек

Проект построен на современном стеке:

*   **Фреймворк**: React с использованием TypeScript.
*   **Сборка**: Vite.
*   **Стилизация**: CSS.
*   **Код**: TypeScript, JavaScript, HTML.

## 🧑‍💻 Установка и запуск проекта

Чтобы запустить приложение локально, выполните следующие шаги:

### Предварительные требования

Убедитесь, что на вашем компьютере установлен **Node.js** и менеджер пакетов **npm** (обычно устанавливается вместе с Node.js).

### Инструкция по запуску

1.  **Клонируйте репозиторий**
    Откройте терминал и выполните команду:
    ```bash
    git clone https://github.com/Emptytytyty/FoodApp.git

2. **Перейдите в папку проекта**
    ```bash
    cd FoodApp

3. **Установите зависимости**
    ```bash
    npm i

4. **Запустите сервер разработки**
    ```bash
    npm run dev

5. **Сборка для продакшена (опционально)**
    ```bash
    npm run build
